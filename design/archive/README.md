# design/archive

Work that was deliberately taken out of the app, kept whole, one zip per removal.

A zip here is not a backup and not a work in progress. It is something that was finished,
shipped or nearly shipped, and then cut on purpose. Each zip carries its own README
saying what it was, why it went, and what was cut out of the files that stayed behind.

- `sat-lessons-2026-09-08.zip` — the entire SAT lesson system: 57 micro-lessons, the
  reader, 3,537 lines of hand-drawn figures, the track map, saved cards. Removed the day
  Prepkin stopped being an SAT app and became a Canvas companion for college
  undergraduates. See `design/SOCIAL-PLAN.md` §0.
