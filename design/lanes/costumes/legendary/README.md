# Legendary costumes, round two (2026-09-11)

Five concept renders for the next legendary tier: Champ, Headliner, Netrunner, Count, Abyss.
Made the same way as `../gen_costumes.py`: the clean mint stage-II still is the base, the
mint Ninja still is the quality bar, Gemini (nano-banana) dresses it. These are REFERENCES,
not costumes: each still has to be built the ninja way (3-5 flat elements from rig geometry)
or through `fit_costume.py` in the Sprout repo, then captured for six coats.

Run: `~/.claude/skills/nano-banana/.venv/bin/python gen_legendary.py [ids]` with
`base-mint.png` and `ref-ninja.png` in the folder (flattened stills, 900px, #F6F4EE).
