FIRST RUN · HANDOFF
Hatch, pick three, first check-off

Two screens, then Home. Nothing is asked for until one task is checked. The prototype on the right is live: type a name, tap rows, check a task off. The chips below it jump to each state for review.

Assumptions. The default kin is the starter slime (ChibiSpecies.catalog[0]), one star. Sprout stills are web art, so every mascot here is a box labeled KIN at the size SproutImage would render. Tab icons and category icons are named placeholders in their dominant colour from PrepkinIcons.swift.

Reasoning. Screen 1 is the only commitment: a name. Screen 2 is only tapping. Home lands with the three rows already there, and the kin's bubble points at the checkbox. Coins fly to the wallet chip because the chip is also the shop door. Offers arrive as cards from the kin, never as screens, and never before the first check.

Colour tokens, reused components, state and copy are in README.md.
